# 기출문제 레퍼런스 자료

Claude가 문제풀이 앱 개발 시 참고하는 원본 기출문제 저장소. 여러 자격증을 다룰 예정이므로 자격증명으로 먼저 분류한다. 기획/설계 문서(`docs/`)와 별개로, 나중에 앱 시드 데이터로도 재사용 가능하도록 구조화한다.

## 폴더 구조

```
data/exam-questions/
  {자격증명}/
    {YYYY-MM-DD}/       # 시행일 (회차 번호 대신 날짜 사용 — 회차는 자격증마다 부여 규칙이 달라 오기 위험이 있음)
      source.pdf         # 원본 PDF
      raw.md              # pymupdf로 추출한 원문 텍스트 (미가공)
      questions.json      # 구조화 데이터 (선택, 파싱 후 생성)
```

예: `유기농업기능사/2016-07-10/raw.md`

## 새 파일 넣는 법 (자동 정리)

1. `{자격증명}{YYYYMMDD}(태그).pdf` 형식의 파일을 `data/exam-questions/` 바로 아래에 놓는다.
   예: `유기농업기능사20160710(교사용).pdf`, `컴퓨터활용능력20240301(정답포함).pdf`
2. `python3 scripts/organize-exam-pdfs.py` 실행 → 자격증/날짜별 폴더로 자동 이동 + `raw.md` 자동 생성.
3. 이미 정리된 폴더(= `source.pdf`가 존재)는 건너뛰므로 중복 실행해도 안전.
4. 파일명이 위 패턴과 다르면 정리되지 않고 `_organize-log.txt`에 SKIP으로 기록됨 — 이 경우 수동으로 자격증명/날짜 확인 후 직접 폴더를 만들어 넣는다.

## raw.md 규칙

- pymupdf(`page.get_text()`)로 추출한 원문 그대로 저장, 사람이 다시 타이핑하지 않는다 (오탈자 위험 방지)
- 상단에 자격증명 / 시행일 / 원본 파일명을 메타데이터로 기록 (스크립트가 자동 생성)
- 문제 안에 굵은 원문자(❶❷❸❹)로 정답이 표시된 "교사용" 자료는 정답까지 같이 보존됨

## questions.json 구조 (파싱 후, 선택 — 아직 자동화 안 됨)

```json
{
  "id": "유기농업기능사-2016-07-10-001",
  "question": "...",
  "choices": ["...", "...", "...", "..."],
  "answer": 2,
  "explanation": "...",
  "category": "..."
}
```

## 주의

- 저작권: 기출문제는 출제기관(큐넷 등) 또는 문제집 제작사(예: comcbt.com) 저작물일 수 있음. 이 폴더는 로컬 개발/AI 참고용이며, 앱에 원문 그대로 대량 포함해 배포할 경우 별도로 라이선스/저작권 확인 필요.
- 개인정보나 민감 정보 없는지 확인 후 커밋.
