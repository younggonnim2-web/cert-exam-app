## Problem Statement

기존 앱은 `lib/examStorage.ts`가 자격증+회차+모드 조합당 "가장 최근 결과 1개"만 저장하고, 결과 화면을 벗어나면(`leaveResult`) 그 결과마저 지운다. 여러 날에 걸쳐 같은 회차를 반복 학습해도 "내가 어떤 문제를 틀렸었는지" 누적 기록이 전혀 남지 않는다. `docs/prd/cert-exam-app.md:86`에 이미 "이력/답안 저장을 로컬에만 할지, 서버+로그인을 붙일지"가 미결정 오픈 이슈로 남아있었다.

## Decisions (사용자 확인 완료)

1. **이력 단위 = 실제 푼 날짜(오늘)**, 회차 시행일이 아니다. "8월 20일에 공부하면서 뭘 틀렸는지" 보기 위한 기능.
2. **대상 모드 = 전체 모의고사 + 과목별 연습 둘 다.**
3. **중복 처리**: 같은 문항을 같은 날 여러 번 틀려도 1건으로 기록(자격증+회차+모드+문항번호+날짜 키). 같은 날 나중에 맞혀도 이력은 지우지 않는다 — "그날 틀렸었다"는 사실을 남기는 게 목적이며, 현재 시점 오답 목록이 아니다.
4. **진입 경로**: 홈 화면(`/`)에 별도 네비게이션 진입점 추가.
5. **저장소 = localStorage.** 서버/로그인이 전혀 없는 순수 정적 Next.js 앱이라 유일한 선택지 — PRD의 오픈 이슈를 "로컬 전용"으로 확정. 기기 간 동기화 없음, 브라우저 데이터 삭제 시 소실됨을 이력 화면에 짧게 안내.

## Premises

1. 서버/로그인 없이 localStorage만으로 구현 가능하다 — 동의 (기존 `examStorage.ts`와 동일한 패턴)
2. 개인 자격증 시험 데이터량(회차당 60문항)에서 오답 이력이 localStorage 용량(수 MB)을 위협할 일은 없다 — 동의
3. 연습 모드는 "제출" 시점이 없으므로(즉시 채점), 오답 선택 즉시 기록하는 것이 유일하게 자연스러운 트리거다 — 동의

## Out of Scope (이번 라운드)

- 이력 삭제/초기화 UI (필요해지면 후속 요청으로)
- 정답 문항까지 포함한 전체 응시 이력 (오답만)
- 서버 동기화/로그인 (PRD 오픈 이슈 중 "로컬 전용" 쪽으로 확정했으므로 당분간 불필요)

## 추가 결정 (2026-08-20, 같은 세션 내 확장)

배포 직후 사용자 요청: 모의고사 결과 화면에서만 보이던 "응시 날짜 + 점수 + 오답 내역"을,
결과 화면을 벗어나도(`leaveResult`가 지워버려도) **언제든 다시 확인할 수 있는 별도 메뉴**로
남겨달라는 요청. 새 메뉴를 또 만들지 않고 기존 `/history`(오답 이력) 화면에 자격증별
"응시 기록" 섹션을 추가하는 것으로 확정 — 진입점 1개 유지, 오답 이력과 같은 화면에서
날짜 축을 공유한다.

- **대상 = 모의고사만.** 과목별 연습은 "제출/합격선" 개념이 없어(즉시 채점) 점수 요약이
  성립하지 않는다 — 기존 오답 이력 섹션은 그대로 두 모드 다 포함.
- **키/중복 처리**: 오답 이력과 동일한 철학 — 자격증+회차+**응시일(오늘 날짜)** 기준. 같은
  날 같은 회차를 다시 봐서 재제출하면 그날의 기록은 최신 결과로 갱신(과거 결과를 덮어씀),
  다른 날 다시 보면 별도 기록으로 쌓인다.
