핵심 흐름 요약
기본 흐름
  1. 자격증 선택 → 회차 선택 (날짜 최신순) → 모드 선택
  2. 전체 모의고사: 상단 문항 상세 패널(지문+보기)에서 답 선택, 이전/다음 버튼 또는 하단 OMR 요약 번호 탭으로 문항 이동 → 답안은 즉시 localStorage에 저장(새로고침/이탈해도 복원) → 잔여 10분부터 타이머가 붉게 긴장감 연출 → 제출 버튼 클릭 또는 타이머 00:00 도달 시 자동 제출 → 결과 화면(점수 + 오답 문항 번호). 정답 여부는 제출 전까지 어디에도 안 보임(일괄채점 원칙)
  3. 과목별 연습: 과목 탭 전환 → 문항 클릭 시 정답이면 초록, 오답이면 빨강으로 즉시 표시 (별도 제출/결과 화면 없음)
엣지 케이스
  1. 회차 선택 화면에서 아직 questions.json이 생성되지 않은 회차는 Empty 상태로 처리 (스크립트 미실행 상황 대비)
  2. 전체모의고사는 클라이언트에서 /api/questions를 fetch하는 구조라 Loading/Error 상태가 실제로 발생 가능 — 과목별연습은 서버 컴포넌트에서 파일을 직접 읽어 이 상태가 사실상 발생하지 않음(참고용으로만 표시)
